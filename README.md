🌦️ Widget de clima en tiempo real
Una aplicación de clima minimalista que utiliza la API de OpenWeatherMap para proporcionar datos meteorológicos precisos y la hora local de cualquier ciudad del mundo en tiempo real.

🚀 Características
Búsqueda Global: Consulta el clima de cualquier ciudad del mundo.

Reloj Mundial: Calcula y muestra la hora local exacta de la ciudad buscada (gestionando husos horarios/timezones).

Datos Detallados: Muestra temperatura, humedad y velocidad del viento.

Interfaz Adaptativa: Diseño 100% Responsive que funciona en móviles, tablets y computadoras.

Iconos Dinámicos: Los iconos cambian automáticamente según el estado del cielo (Nubes, Lluvia, Despejado, etc.).

Manejo de Errores: Alerta visual si la ciudad ingresada no existe.

🛠️ Tecnologías

HTML5: Estructura semántica del sitio.

CSS3: Estilos personalizados, Flexbox y Media Queries.

JavaScript (ES6+): Manipulación del DOM, Fetch API y lógica de tiempo real.

OpenWeatherMap API: Fuente de datos meteorológicos.

Google Fonts: Tipografía "Poppins" para un diseño limpio.
